실습 문제: 올인원 미니 POS & 매출 분석기 (app.py)

기존 common.py(parse_sales, summarize)를 활용하여 Streamlit 기반 통합 웹 앱을 구현하고 배포한 후 url 올려주세요.

1. 기본 환경 및 모듈 임포트

  • 파일명은 posapp.py로 작성하며, 같은 프로젝트 구조에서 data/sales.csv 경로를 참조할 수 있도록 pathlib.Path를 사용합니다.
  • pandas를 pd로, streamlit을 st로 임포트하고, common 모듈에서 parse_sales와 summarize를 가져옵니다.
  • 페이지 설정은 page_title="미니 POS & 매출 대시보드", layout="wide"로 지정합니다.
  • 상단 제목은 "🏪올인원 미니 POS & 매출 분석기", 본문 설명은 "**학습 목표**: 입력(`form`), 상태 유지(`session_state`), 캐싱(`cache_data`), 데이터 시각화를 하나로 통합합니다."로 출력합니다.

2. 세션 상태 및 캐싱 함수

  • st.session_state에 "pos_orders"가 없으면 빈 리스트 []로 초기화합니다.
  • st.session_state에 "messages"가 없으면 초기 안내 메시지 1개를 담은 리스트로 초기화합니다:
    [{"role": "assistant", "content": "안녕하세요! '총매출', '인기상품', '주문건수' 등을 물어보세요."}]
  • @st.cache_data(ttl=60) 데코레이터를 적용한 get_cached_summary(rows) 함수를 정의하고 내부에서 summarize(rows)를 반환합니다.

3. 사이드바 데이터 로드 및 초기화

  • 사이드바 헤더로 st.sidebar.header("⚙️ 데이터 관리")를 표시합니다.
  • st.sidebar.file_uploader("추가 매출 CSV 업로드 (UTF-8)", type=["csv"])로 uploaded를 받습니다.
  • "요약 캐시 초기화" 버튼 클릭 시 get_cached_summary.clear()를 호출하고 st.sidebar.success("캐시를 초기화했습니다.")를 출력합니다.
  • "POS 입력 내역 초기화" 버튼 클릭 시 st.session_state.pos_orders = []로 비우고 st.sidebar.warning("현장 주문 내역이 초기화되었습니다.")를 출력합니다.
  • base_rows 생성 규칙:
    1. uploaded가 있으면 parse_sales(uploaded.getvalue())를 호출해 base_rows에 저장하고 st.sidebar.success(f"CSV에서 {len(base_rows)}행을 불러왔습니다.")를 출력합니다. ValueError 발생 시 st.sidebar.error(str(exc))를 출력합니다.
    2. uploaded가 없으면 Path(__file__).resolve().parent / "data" / "sales.csv" 경로를 확인합니다. 파일이 존재하면 parse_sales(sample_path.read_bytes())로 읽고, 없으면 기본값 [{"product": "book", "quantity": 2, "price": 12000}, {"product": "pen", "quantity": 5, "price": 1500}]을 사용합니다.
  • 최종 데이터는 all_rows = base_rows + st.session_state.pos_orders로 합칩니다.

4. 메인 3개 탭 구현 요구사항

st.tabs(["📊 매출 대시보드", "💳 POS 주문 입력", "💬 매출 도우미 챗봇"])으로 tab1, tab2, tab3을 생성합니다.

탭 1: 📊 매출 대시보드

  • 상품 선택 셀렉트박스: 라벨 "조회할 상품 선택", 선택지 ["전체"] + sorted({row["product"] for row in all_rows}).
  • "전체" 선택 시 all_rows, 특정 상품 선택 시 [r for r in all_rows if r["product"] == selected]로 filtered를 만들고 summary = get_cached_summary(filtered)를 계산합니다.
  • 3열(st.columns(3)) 메트릭 출력:
    • col1.metric("총매출", f"{summary['revenue']:,}원")
    • col2.metric("총 판매 수량", f"{summary['quantity']:,}개")
    • col3.metric("거래 건수", f"{len(filtered)}건")
  • 하단 2열(st.columns([1.2, 1])):
    • 왼쪽(left): 서브헤더 "상세 거래 내역". filtered가 있으면 df = pd.DataFrame(filtered)에 df["subtotal"] = df["quantity"] * df["price"]를 추가한 뒤 st.dataframe(df, use_container_width=True, hide_index=True)로 출력하고, 비어 있으면 st.info("표시할 데이터가 없습니다.")를 출력합니다.
    • 오른쪽(right): 서브헤더 "상품별 매출 비중". summary["by_product"]가 참일 때 st.bar_chart(summary["by_product"])를 출력합니다.

탭 2: 💳 POS 주문 입력

  • 서브헤더 "신규 현장 주문 등록" 아래에 st.form("pos_form", clear_on_submit=True) 폼을 구성합니다.
  • 입력 위젯:
    • p_name = st.text_input("상품명 (1~40자)")
    • c1, c2 = st.columns(2) 내부에 p_qty = c1.number_input("수량", min_value=1, max_value=1000, value=1) 및 p_price = c2.number_input("단가 (원)", min_value=100, max_value=1_000_000, value=5000, step=500)
    • 제출 버튼: submitted = st.form_submit_button("주문 추가")
  • 제출 시 clean_name = p_name.strip()을 검증합니다. not clean_name or len(clean_name) > 40이면 st.error("상품명은 공백 제외 1~40글자로 입력하세요.")를 출력하고, 유효하면 st.session_state.pos_orders에 {"product": clean_name, "quantity": int(p_qty), "price": int(p_price)}를 추가한 뒤 st.success(f"'{clean_name}' {p_qty}개 (총 {p_qty * p_price:,}원) 주문이 등록되었습니다! 대시보드 탭에서 확인하세요.")를 출력합니다.

탭 3: 💬 매출 도우미 챗봇

  • 서브헤더 "데이터 기반 간단 Q&A" 아래에 st.session_state.messages의 각 메시지를 st.chat_message(msg["role"])과 st.write(msg["content"])로 렌더링합니다.
  • st.chat_input("매출에 대해 질문해보세요 (예: 총매출 알려줘, 가장 잘 팔린 상품은?)")으로 입력을 받으면 사용자 메시지를 st.session_state.messages에 추가하고 화면에 표시합니다.
  • total_summary = get_cached_summary(all_rows) 기준으로 응답 문자열 reply를 생성합니다:
    • "총매출" in prompt or "매출" in prompt: f"현재 누적 총매출은 **{total_summary['revenue']:,}원**입니다."
    • "인기" in prompt or "가장" in prompt or "상품" in prompt: total_summary["by_product"]가 있으면 best = max(total_summary["by_product"].items(), key=lambda x: x[1])로 f"매출 1위 상품은 **{best[0]}**이며, 총 **{best[1]:,}원**의 매출을 기록했습니다.", 없으면 "아직 등록된 상품 데이터가 없습니다."
    • "수량" in prompt or "건수" in prompt: f"총 거래 건수는 **{len(all_rows)}건**, 총 판매 수량은 **{total_summary['quantity']:,}개**입니다."
    • 그 외: "질문을 이해하지 못했습니다. **'총매출'**, **'인기 상품'**, **'판매 수량'** 키워드를 포함해 질문해 주세요!"
  • reply를 st.session_state.messages에 "assistant" 역할로 추가하고 st.chat_message("assistant")로 출력합니다.
