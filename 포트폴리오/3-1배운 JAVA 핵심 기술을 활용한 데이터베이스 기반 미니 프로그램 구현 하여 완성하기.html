도서 관리 시스템 요구사항 명세서

1. 프로젝트 개요

본 문서는 Java의 핵심 문법(Class, Interface, Array/Collection, JDBC)을 활용한 콘솔 기반 도서 관리 시스템의 요구사항을 정의합니다. 사용자는 터미널 환경에서 도서를 등록 및 조회할 수 있으며, 데이터는 관계형 데이터베이스(RDBMS)에 영구적으로 보존됩니다.

2. 비기능적 요구사항

본 프로그램은 객체지향 설계의 기초와 데이터베이스 연동을 다지기 위해 다음 기술적 요소들을 반드시 포함해야 합니다.

클래스 (Class) 객체지향의 캡슐화 원칙에 따라 데이터 필드는 private으로 선언하고 Getter/Setter를 통해 접근합니다.
인터페이스 (Interface) 구현체(DAO)와의 결합도를 낮추기 위해 시스템의 주요 기능을 추상 메서드로 정의한 인터페이스를 사용합니다.
배열 및 컬렉션 (Array / List) 컬렉션 프레임워크(List<Book>)를 사용하거나, 고정 크기의 객체 배열 Book[]을 사용하여 조회된 데이터를 관리합니다.
데이터베이스 연동 (JDBC) java.sql 패키지(Connection, PreparedStatement, ResultSet)를 사용하여 데이터베이스 테이블에 데이터를 읽고 쓰는 로직을 구현합니다.

3. 기능적 요구사항

요구사항-01 데이터 초기화 및 연결 (Connect & Load)

프로그램 실행 시 데이터베이스에 연결하고 books 테이블을 조회(SELECT)하여 기존에 저장된 도서 데이터를 읽어와 배열(또는 리스트)에 할당합니다.

요구사항-02 도서 정보 등록 (Add)

사용자로부터 도서 번호, 제목, 저자명을 입력받아 Book 객체를 생성하고, 데이터베이스 테이블에 즉시 저장(INSERT)하거나 메모리에 적재합니다. 중복된 ID나 제약 조건 위반 시 적절한 예외 메시지를 출력합니다.

요구사항-03 전체 목록 조회 (List)

데이터베이스(또는 동기화된 배열)에 저장된 모든 도서 리스트를 콘솔에 표 형태로 출력합니다. 저장된 도서가 없을 경우 "등록된 도서가 없습니다"라는 안내 문구를 표시합니다.

요구사항-04 데이터 동기화 및 자원 해제 (Commit & Exit)

프로그램 종료 시 변경된 데이터를 데이터베이스에 최종 반영(Commit)하고, 사용 중이던 DB 연결 자원(Connection, Statement, ResultSet)을 안전하게 해제(Close)합니다.

4. 시스템 설계 상세

4.1. 인터페이스 정의

public interface Manageable {
    void addItem(Book book);    // 도서 데이터 추가 (INSERT)
    void displayAll();          // 전체 도서 목록 출력
    void saveToDB();            // 데이터베이스에 데이터 저장/동기화
    void loadFromDB();          // 데이터베이스에서 데이터 로드 (SELECT)
}

4.2. 데이터 모델 (Book Class)

  • id: int (도서 식별 번호, Primary Key)
  • title: String (도서 제목)
  • author: String (저자명)
  • toString(): 콘솔 출력 시 사용할 포맷 문자열 반환 메서드

4.3. 데이터베이스 테이블 스키마 (SQL)

CREATE TABLE books (
    id INT PRIMARY KEY,
    title VARCHAR(100) NOT NULL,
    author VARCHAR(50) NOT NULL
);
