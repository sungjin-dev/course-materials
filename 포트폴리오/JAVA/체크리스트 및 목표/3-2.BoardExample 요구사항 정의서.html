자바 게시판 시스템 (BoardExample) 요구사항 정의서

JDBC와 표준 Java 문법을 활용한 기초 CRUD 게시판 구현 프로젝트

1. 프로젝트 개요

본 프로젝트는순수 자바 클래스와 JDBC를 사용하여 데이터베이스(boards 테이블) 연동 기능을 구현합니다.

2. 데이터 모델 (Board 클래스)

  • ● 필드 캡슐화: 모든 필드는 private으로 선언하여 외부로부터의 직접 접근을 제한합니다.
  • ● 표준 메소드 작성:
    • - 각 필드에 대한 Getter/Setter 메소드를 직접 작성합니다.
    • - 객체 정보를 쉽게 확인할 수 있도록 toString() 메소드를 오버라이딩합니다.
    • - 필요 시 기본 생성자와 전체 필드 생성자를 정의합니다.

3. 기능 요구사항

메인 메뉴 구성

  • 1. Create: 게시물 등록 (제목, 내용, 작성자 입력)
  • 2. Read: 상세 내용 조회 (글 번호 선택)
  • 3. Clear: 모든 게시물 삭제 (전체 삭제 실행)
  • 4. Exit: 프로그램 및 DB 연결 종료

입력 제어

표준 입력을 위해 Scanner 객체를 생성하고, 공백을 포함한 문자열 처리를 위해 nextLine()을 주력으로 사용합니다.

💡 목록 출력 (list)

DB로부터 SELECT * FROM boards 쿼리를 실행하여 결과 집합(ResultSet)을 Board 객체 리스트로 변환 후 화면에 출력합니다.

💡 상세 보기 및 보조 메뉴 (read)

특정 번호를 입력받아 상세 내용을 보여준 후, Update(수정) 또는 Delete(삭제) 기능을 선택할 수 있는 분기 로직을 포함합니다.

💡 데이터 수정 및 삭제

사용자에게 수정할 제목/내용을 입력받아 UPDATE 명령을 수행하거나, 선택된 객체의 bno를 사용하여 DELETE 명령을 수행합니다.

4. 핵심 구현 가이드

객체 지향 원칙

데이터 필드는 private으로, 메소드는 public으로 선언하여 자바의 정보 은닉 원칙을 준수하세요.

리소스 관리

Connection, PreparedStatement 등 JDBC 객체는 사용 후 반드시 close()를 호출하여 자원 누수를 방지하세요.
