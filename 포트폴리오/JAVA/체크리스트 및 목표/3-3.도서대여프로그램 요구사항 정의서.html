도서 대여 프로그램 요구사항 정의서

Java & Oracle 기반 도서 관리 시스템

1. 시스템 개요

  • 목적: 도서관 또는 대여점의 도서 관리, 회원 관리, 대여 및 반납 프로세스를 전산화하여 업무 효율성을 높이고 사용자 편의를 제공합니다.
  • 개발 언어: Java
  • 데이터베이스: Oracle Database (JDBC를 통한 데이터 연동)

2. 기능적 요구사항 (Functional Requirements)

기능은 공통, 사용자, 관리자로 구분하여 정의

2.1 공통 기능

기능 ID 기능명 설명
COM-001 로그인 및 로그아웃 아이디와 비밀번호를 입력하여 시스템에 접속 및 종료합니다.
COM-002 회원가입 신규 사용자가 아이디, 비밀번호, 이름, 연락처 등을 입력하여 계정을 생성합니다.
COM-003 도서 검색 도서명, 저자, 출판사, 카테고리 등의 키워드로 도서를 검색

2.2 일반 사용자 (User) 기능

USR-001 [도서 대여]

  • 대여 가능한 상태의 도서를 선택하여 대여를 신청합니다.
  • 1인당 최대 대여 가능 권수(예: 3권) 및 대여 기간(예: 7일) 제한을 적용받습니다.

USR-002 [도서 반납]

  • 본인이 대여 중인 도서를 조회하고 반납 처리를 진행합니다.
  • 반납 예정일이 지난 경우 연체 상태로 전환되며 시스템 알림을 받습니다.

USR-003 [마이페이지 (대여 내역 조회)]

  • 현재 대여 중인 도서 목록 및 과거의 총 대여 이력을 조회합니다.
  • 연체된 도서가 있는지, 연체료 또는 대여 정지 기간이 있는지 확인합니다.

USR-004 [개인정보 수정]

  • 본인의 비밀번호, 연락처 등 개인정보를 수정하거나 회원 탈퇴를 요청할 수 있습니다. (단, 미반납 도서가 있을 경우 탈퇴 불가)

2.3 관리자 (Administrator) 기능

ADM-001 [도서 관리 (CRUD)]

  • 등록: 신규 도서의 정보(ISBN, 제목, 저자, 출판사, 분류, 입고일)를 시스템에 등록합니다.
  • 수정/삭제: 기존 도서 정보를 수정하거나, 분실/파손된 도서를 삭제(또는 폐기 상태로 변경)합니다.

ADM-002 [회원 관리]

  • 전체 사용자 목록을 조회하고, 특정 회원의 상세 정보 및 대여 이력을 확인합니다.
  • 악성 이용자(장기 연체자 등)의 계정을 정지하거나 강제 탈퇴 처리할 수 있습니다.

ADM-003 [대여/반납 총괄 관리]

  • 전체 회원의 실시간 대여 현황 및 미반납(연체) 현황을 조회합니다.
  • 시스템 오류 발생 시 관리자 권한으로 강제 대여/반납 처리를 수행할 수 있습니다.

ADM-004 [통계 조회 (선택 사항)]

  • 가장 많이 대여된 인기 도서 순위, 월별 대여 건수 등의 통계 데이터를 확인합니다.

4. 데이터베이스 (Oracle) 설계 요구사항 요약

성공적인 기능 구현을 위해 다음과 같은 핵심 테이블 구조가 필요.

MEMBER

회원 테이블

회원ID(PK), 비밀번호, 이름, 연락처, 가입일, 대여정지여부

BOOK

도서 테이블

도서번호(PK), ISBN, 도서명, 저자, 출판사, 대여가능여부

RENTAL

대여 내역 테이블

대여번호(PK), 회원ID(FK), 도서번호(FK), 대여일, 반납예정일, 실제반납일, 연체여부
