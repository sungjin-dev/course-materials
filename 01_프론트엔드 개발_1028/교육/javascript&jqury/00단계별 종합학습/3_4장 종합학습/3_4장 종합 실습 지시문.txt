[실습 지시문] 자바스크립트 제어문 및 객체 통합 구현
1. 제어문 (3장) 관련 지시사항

사용자 입력 검증: if...else 문을 사용하여 사용자가 입력한 데이터의 유효성을 검사하고, 당첨 여부에 따라 서로 다른 결과 메시지를 출력하도록 조건 분기를 설정하세요.

상태 시각화: for 반복문을 활용하여 추첨이 진행되는 과정을 화면에 숫자로 순차적으로 표시하여 사용자에게 대기 시간을 시각적으로 제공하세요.

2. 내장 객체 (4장) 관련 지시사항

실시간 날짜 처리: Date 객체를 생성하고 getFullYear(), getMonth(), getDate() 메서드를 호출하여 프로그램 실행 시점의 연, 월, 일 정보를 추출해 화면에 명시하세요.

데이터 목록 관리: Array 객체를 생성하여 추첨 대상이 되는 경품 데이터들을 인덱스 구조로 저장하고 관리하세요.

무작위 로직 구현: Math.random()으로 생성된 난수에 배열의 길이를 곱하고, Math.floor()를 적용하여 경품 배열의 인덱스 범위 내에서 무작위 번호를 추출하는 로직을 작성하세요.

3. 브라우저 객체 (4장) 관련 지시사항

동적 데이터 수집: window.prompt() 대화상자를 실행하여 사용자로부터 이름을 입력받고, 이를 변수에 저장하여 프로그램 전반에서 활용하세요.

URL 정보 참조: location.href 속성을 참조하여 현재 사용자가 접속 중인 웹 페이지의 전체 주소 정보를 문서 하단에 실시간으로 표시하세요.
