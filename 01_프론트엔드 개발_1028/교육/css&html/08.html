08-1 블록과 인라인 요소의 실전 코드

/* 1. CSS: 성질 강제 변경하기 */
.block-span { display: block; background: #38bdf8; }
.inline-p { display: inline; border: 1px solid white; }
<!-- 2. HTML: 각 요소의 기본 배치 -->
<h1>블록 레벨 요소</h1> <!-- 한 줄 전체 차지 -->
<p>단락 태그도 블록입니다.</p>
<span>인라인 요소 1</span> <!-- 옆으로 나란히 배치 -->
<span>인라인 요소 2</span>
<span class="block-span">블록이 된 인라인 요소</span>

display 속성

  • block: 항상 새 줄에서 시작하며 가로폭 100%를 차지합니다.
  • inline: 콘텐츠 크기만큼만 영역을 차지하며 줄바꿈이 없습니다.
  • none: 화면에서 완전히 제거합니다.

08-1 박스 모델 상세 구현

/* CSS: 박스 영역 상세 설정 */
.box-example {
width: 250px; height: 100px;
background-color: #1e293b;
padding: 20px; /* 콘텐츠-테두리 사이 여백 */
border: 4px solid #38bdf8; /* 테두리 두께/종류/색상 */
margin: 30px; /* 테두리 외부 여백 */
}
<!-- HTML: 적용 구조 -->
<div class="box-example">
Box Model Content
</div>

Padding은 배경 이미지가 적용되는 영역이며, Margin은 이웃 요소와의 간격을 생성합니다.

08-1 박스 크기 계산 (Box-Sizing) 비교

/* 1. content-box: 여백이 너비에 추가됨 */
.c-box {
box-sizing: content-box;
width: 300px; padding: 30px; border: 10px;
}
/* 2. border-box: 여백이 너비 안에 포함됨 */
.b-box {
box-sizing: border-box;
width: 300px; padding: 30px; border: 10px;
}
<!-- HTML: 실제 크기 비교 -->
<div class="c-box">전체 가로 380px</div>
<div class="b-box">전체 가로 300px</div>

실무 표준

  • content-box: 기본값. 레이아웃 설계 시 크기 계산이 복잡해집니다.
  • border-box: 패딩과 테두리를 포함하여 너비를 유지하므로 레이아웃 설계가 훨씬 쉽습니다.

08-2 테두리 스타일과 HTML 적용

/* CSS: 테두리 종류 및 곡률 */
.border-dashed { border: 2px dashed white; }
.border-double { border: 4px double #38bdf8; }
.profile-img {
width: 100px; height: 100px;
border-radius: 50%; /* 원형 만들기 */
}
<!-- HTML: 다양한 테두리 요소 -->
<div class="border-dashed">점선 테두리</div>
<button class="border-double">이중선 버튼</button>
<img src="user.jpg" class="profile-img" alt="프로필">

Border Radius

  • radius: 수치가 커질수록 모서리가 둥글어집니다.
  • 50%: 정사각 요소의 경우 완벽한 원을 만듭니다.
  • border-style: none, solid, dotted, dashed, double 등.

08-3 여백 축약형과 중앙 정렬

/* CSS: 상 우 하 좌 축약형 */
.shorthand {
margin: 10px 20px 30px 40px; /* 시계방향 */
padding: 20px 50px; /* 상하 20, 좌우 50 */
}
/* 블록 요소 가로 중앙 정렬 핵심 코드 */
.center-block {
width: 80%;
margin: 0 auto; /* 상하 0, 좌우 자동 */
}
<!-- HTML: 레이아웃 예시 -->
<div class="center-block">
<p class="shorthand">여백이 적용된 콘텐츠 영역</p>
</div>

정렬과 여백

  • margin auto: 블록 레벨 요소에서 남은 공간을 좌우로 분할하여 중앙에 배치합니다.
  • 상세 여백: margin-top, padding-left 처럼 개별 속성으로도 지정 가능합니다.
