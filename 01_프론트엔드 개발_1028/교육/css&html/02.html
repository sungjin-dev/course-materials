02-1. 텍스트 덩어리로 묶기 (1) <hn>, <p>, <br>

<!-- 1. 제목 표시 -->
<h1>
가장 큰 제목
</h1>
<h6>
가장 작은 제목
</h6>
<!-- 2. 단락과 줄바꿈 -->
<p>
입력한 내용 앞뒤로 빈 줄이 생기며
<br>
단락 내에서 줄이 바뀝니다.
</p>

제목 (<hn>)

  • 웹 콘텐츠 영역의 제목을 표시.
  • 크기 순서: h1 (가장 큼) ~ h6 (가장 작음).

단락 (<p>) & 줄바꿈 (<br>)

  • <p>: 텍스트 단락 생성. 앞뒤로 빈 줄 자동 삽입.
  • <br>: 강제 줄바꿈. 닫는 태그가 없음.

02-1. 텍스트 덩어리로 묶기 (2) <blockquote>, <hr>, <pre>

<!-- 1. 인용문 -->
<blockquote>
다른 텍스트보다 안으로 들여 써짐.
</blockquote>
<!-- 2. 수평 줄 (분위기 전환) -->
<hr>
<!-- 3. 원본 그대로 표시 -->
<pre>
공백이나 띄어쓰기가
입력한 그대로 유지됩니다.
</pre>

인용문 (<blockquote>)

  • 인용 내용을 표시하며, 기본적으로 들여쓰기 적용.

수평 줄 (<hr>)

  • 주제가 바뀔 때 분위기 전환 용도. 닫는 태그 없음.

원본 유지 (<pre>)

  • 소스 코드의 공백과 줄바꿈을 있는 그대로 브라우저에 표시.

02-2. 텍스트 한 줄로 표시하기 (1) <strong>, <b>, <em>, <i>

<!-- 1. 굵게 표시 -->
<p>
<strong>
중요한 내용 강조
</strong>
<b>
단순히 굵게 표시
</b>
</p>
<!-- 2. 이탤릭체 표시 -->
<p>
<em>
흐름상 강조 (이탤릭)
</em>
<i>
단순 이탤릭체
</i>
</p>

굵게 표시 (<strong>, <b>)

  • <strong>: 내용이 중요하여 강조할 때 사용 (시맨틱).
  • <b>: 의미적 강조 없이 시각적으로만 굵게 표시.

이탤릭체 (<em>, <i>)

  • <em>: 문장 흐름상 특정 부분을 강조할 때 (시맨틱).
  • <i>: 의미적 강조 없이 시각적으로만 이탤릭체로 표시.

02-2. 텍스트 한 줄로 표시하기 (2) <q>, <mark>, <span>, <div>

<p>
<q>
줄바꿈 없는 인용 (따옴표 추가)
</q>
<mark>
형광펜 배경색 효과
</mark>
</p>
<div>
<span>
줄 안에서 인라인으로 묶기
</span>
</div>

짧은 인용 & 하이라이트

  • <q>: 줄바꿈 없이 한 줄로 표시. 앞뒤에 자동으로 따옴표("") 추가.
  • <mark>: 묶은 부분의 배경색(노란색)이 적용되어 형광펜 효과.

영역 묶기 (<span>, <div>)

  • <span>: 줄 안에서 텍스트 일부만 묶을 때 (인라인).
  • <div>: 줄을 바꿔 하나의 독립된 단락/블록으로 묶을 때 (블록).

02-3. 목록을 만드는 태그 (1) <ul>, <ol>, <li>

<!-- 순서 없는 목록 -->
<ul>
<li>
불릿 기호 1
</li>
</ul>
<!-- 순서 있는 목록 -->
<ol type="a" start="3">
<li>
c. 항목
</li>
</ol>

순서 없는 목록 (<ul>, <li>)

  • 각 항목 앞에 불릿(점)이 붙습니다.
  • CSS의 list-style-type으로 불릿 모양 변경 가능.

순서 있는 목록 (<ol>, <li>)

  • 각 항목 앞에 숫자나 알파벳이 순서대로 붙습니다.
  • type: 숫자, 알파벳, 로마자 등 종류 지정.
  • start: 중간 번호부터 시작하도록 설정.
  • reversed: 역순으로 번호 표시.

02-3. 목록을 만드는 태그 (2) <dl>, <dt>, <dd>

<!-- 설명 목록 -->
<dl>
<dt>
올레 1코스 (제목)
</dt>
<dd>
코스: 시흥 초등학교 옆 (설명 1)
</dd>
<dd>
거리: 14.6km (설명 2)
</dd>
</dl>

설명 목록 (<dl>, <dt>, <dd>)

  • '제목(용어)'과 그에 대한 '설명'으로 이루어진 특수 목록입니다.
  • <dl>: 설명 목록 전체를 감싸는 태그.
  • <dt>: 제목이나 용어를 나타냅니다.
  • <dd>: 해당 용어에 대한 설명을 나타냅니다.
  • 하나의 <dt> 제목 아래에 여러 개의 <dd> 설명을 가질 수 있습니다.

02-4. 표를 만드는 태그 (1) <table>, <tr>, <th>, <td>

<table border="1">
<tr>
<th>
제목 셀
</th>
<td>
데이터 셀
</td>
</tr>
</table>

표 기본 구성 요소

  • 자료를 보기 좋게 그리드 형태로 정리합니다.
  • <table>: 표 전체를 묶어주는 래퍼 태그.
  • <tr> (Table Row): 표의 한 행(가로줄)을 정의합니다.
  • <th> (Table Head): 제목 셀. 글자가 굵게 표시되며 중앙 정렬됩니다.
  • <td> (Table Data): 일반 데이터 셀. 행 안에 열을 형성합니다.

02-4. 표를 만드는 태그 (2) colspan, rowspan

<table border="1">
<tr>
<th rowspan="2">
세로 2칸 병합
</th>
<td colspan="3">
가로 3칸 병합
</td>
</tr>
</table>

셀 병합 속성

  • 테이블의 여러 셀(칸)을 하나로 합칠 때 사용합니다. <td>나 <th> 태그의 속성으로 적용.
  • colspan="합칠 열의 수": 가로 방향(열, Column)으로 인접한 셀을 하나로 합칩니다.
  • rowspan="합칠 행의 수": 세로 방향(행, Row)으로 인접한 셀을 하나로 합칩니다.

02-4. 표를 만드는 태그 (3) <caption>, <figure>

<figure>
<figcaption>
자유로운 위치의 표 제목
</figcaption>
<table border="1">
<caption>
상단 중앙 고정 제목
</caption>
<tr>
<td>
데이터
</td>
</tr>
</table>
</figure>

표에 제목 달기

  • <caption>: 표의 위쪽 중앙에 제목이 표시됩니다. <table> 태그 바로 아래에 작성해야 합니다.
  • <figure> & <figcaption>: <figure>로 테이블을 감싸고, <figcaption>을 위나 아래에 배치하여 원하는 위치(상/하)에 제목을 표시할 수 있습니다.

02-4. 표를 만드는 태그 (4) <thead>, <tbody>, <tfoot>

<table border="1">
<thead>
<tr>
<th>
제목
</th>
</tr>
</thead>
<tbody>
<tr>
<td>
본문 데이터
</td>
</tr>
</tbody>
<tfoot>
<tr>
<th>
요약/합계
</th>
</tr>
</tfoot>
</table>

표의 구조화 (Semantic)

  • 표를 제목(thead), 본문(tbody), 요약/바닥(tfoot) 세 가지 논리적 영역으로 분리.
  • 화면 낭독기(스크린 리더)가 표의 구조를 쉽게 파악할 수 있어 웹 접근성이 향상됩니다.
  • 자바스크립트/CSS를 통해 본문이 길 경우 제목(thead)을 고정하고 본문만 스크롤되도록 UI 처리가 용이합니다.

02-4. 표를 만드는 태그 (5) <col>, <colgroup>

<table border="1">
<caption>
colgroup 연습
</caption>
<colgroup>
<col>
<col span="2" style="background-color:blue;">
<col style="background-color:yellow">
</colgroup>
<tr>
<td>
데이터1
</td>
<td>
데이터2
</td>
<td>
데이터3
</td>
<td>
데이터4
</td>
</tr>
</table>

열 단위 스타일 일괄 지정

  • <col>: 한 열의 모든 셀에 같은 스타일을 적용할 때 사용합니다. (닫는 태그 없음)
  • span 속성: <col span="2">처럼 여러 열을 하나로 묶어 처리.
  • <colgroup>: 여러 개의 <col> 태그를 그룹으로 묶습니다.
  • 주의: 반드시 <caption> 뒤에 위치해야 하며, <tr>이나 <td>보다 먼저 작성해야 합니다. 선언된 열의 총개수(span 포함)가 표의 열 개수와 일치해야 합니다.
