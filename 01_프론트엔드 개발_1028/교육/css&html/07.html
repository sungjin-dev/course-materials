07. CSS 색상과
배경 스타일

구조(HTML)와 디자인(CSS)의 연동

[수업 내용]

- HTML 요소에 색상 적용하기
- 배경 이미지 위치와 고정 기술
- CSS만으로 만드는 화려한 패턴

07-1 색상 표기법과 적용 구조

/* CSS 스타일 정의 */
.text-hex { color: #38bdf8; }
.bg-rgba { background: rgba(56, 189, 248, 0.2); }
<!-- HTML 적용 예시 -->
<p class="text-hex">16진수 색상 텍스트</p>
<div class="bg-rgba">투명도가 적용된 배경 박스</div>
/* 실무 Tip: HSL을 이용한 버튼 강조 */
.btn { background: hsl(200, 100%, 50%); }
.btn:hover { background: hsl(200, 100%, 40%); }

HTML과 CSS 연결

  • 선택자: HTML의 class와 CSS의 . 기호를 연결합니다.
  • rgba: 투명 배경 요소는 내부 텍스트에 영향을 주지 않고 배경만 조절할 때 사용합니다.

07-2 배경 이미지 제어와 HTML 구조

/* CSS: 메인 히어로 섹션 설정 */
.hero {
height: 500px;
background-image: url('sky.jpg');
background-position: center;
background-attachment: fixed;
}
<!-- HTML: 섹션 구성 -->
<section class="hero">
<h1>패럴랙스 배경 효과</h1>
</section>

화면 고정 기법

  • Fixed: 스크롤 시 배경 이미지는 움직이지 않고 콘텐츠만 이동합니다.
  • Center: 반응형 웹에서 핵심 피사체를 가운데 유지시킵니다.

07-2 배경 적용 범위 실습 예제

/* CSS: 테두리와 배경의 기점 관계 */
.box {
width: 200px; padding: 20px;
border: 10px dashed white;
background-image: url('pattern.png');
background-origin: content-box;
}
<!-- HTML: 콘텐츠 박스 -->
<div class="box">내용 영역에서 이미지가 시작됨</div>

Box Model 연동

  • Content-box: 텍스트가 시작되는 안쪽 영역부터 배경 이미지가 배치됩니다.
  • Dashed Border: 테두리 틈새로 배경이 보이는지 여부는 clip 속성으로 제어합니다.

07-3 그러데이션 패턴 코드 예제

/* CSS: 반복 선형 그러데이션 패턴 */
.stripe-pattern {
width: 100%; height: 100px;
background: repeating-linear-gradient(
45deg,
#38bdf8, #38bdf8 10px,
#020617 10px, #020617 20px
);
}
<!-- HTML: 패턴을 채울 요소 -->
<div class="stripe-pattern"></div>

패턴 디자인

  • Hard-stop: 10px 지점에서 색상을 급격히 변경하여 선명한 줄무늬를 만듭니다.
  • Angle: 45deg를 통해 사선 무늬를 구현했습니다.

07-2 배경 속성 축약형 적용

/* CSS: 모든 배경 설정을 한 줄로 */
.card-bg {
background: #0b1120 url('logo.svg') no-repeat center / contain;
}
<!-- HTML: 카드 컴포넌트 -->
<div class="card-bg">
<p>배경 정보가 축약 적용됨</p>
</div>

축약형 문법

  • / : 위치(position)와 크기(size) 사이에는 반드시 슬래시를 넣어야 합니다.
  • 우선순위: 축약형은 개별 속성(color, image 등)보다 나중에 선언되면 모든 개별 설정을 덮어씁니다.
