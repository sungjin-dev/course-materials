04-1. 폼 만들기 <form>

<!-- 폼 영역의 시작 -->
<form
action="register.jsp"
method="post"
name="member_form"
target="_blank">
<!-- 사용자 입력 폼 요소들이 위치 -->
<input type="text" name="uid">
<input type="submit" value="가입">
</form>

<form> 태그의 역할

  • 사용자가 입력한 정보를 서버 프로그램(JSP, PHP 등)으로 전달하는 기본 틀입니다.

핵심 속성(Attributes)

  • action: 폼 태그 안의 내용을 처리해 줄 서버 프로그램의 주소(경로).
  • method: 정보를 서버로 넘겨주는 방식.
    - get: 주소 표시줄에 입력값이 노출됨 (256~4096바이트 제한).
    - post: 표준 입력으로 넘겨받아 데이터가 숨겨짐 (길이 제한 없음, 보안에 유리).
  • name: 폼의 이름 (JS에서 폼을 제어할 때 사용).

04-1. 폼 요소 그룹화 <fieldset>, <legend>, <label>

<form>
<fieldset>
<legend>
개인 정보
</legend>
<!-- label로 입력창 설명 연결 -->
<label for="user_id">
아이디(6자 이상)
</label>
<input
type="text"
id="user_id">
</fieldset>
</form>

폼 묶어주기

  • <fieldset>: 하나의 폼 안에서 여러 구역을 나누어 외곽선으로 묶어줍니다.
  • <legend>: 묶은 그룹(fieldset)의 제목을 지정합니다.

레이블 연결 (<label>)

  • 폼 요소에 이름표(텍스트)를 붙여줍니다.
  • 레이블의 for 속성값과 폼 요소(input)의 id 속성값을 일치시키면, 텍스트만 클릭해도 입력창에 커서가 활성화되어 접근성 및 사용성이 크게 향상됩니다.

04-2. <input> 기본 텍스트 text, password, hidden

<!-- 1. 한 줄 텍스트 입력 -->
<input
type="text"
name="user_name"
size="10"
maxlength="15">
<!-- 2. 비밀번호 입력 (마스킹 처리) -->
<input
type="password"
name="user_pw">
<!-- 3. 사용자에게 보이지 않는 데이터 -->
<input
type="hidden"
name="admin_code"
value="A001">

기본 입력창

  • type="text": 기본 텍스트 필드. size로 화면 길이 조절, maxlength로 최대 글자 수 제한 가능.
  • type="password": 입력 내용이 *나 •으로 가려지는 비밀번호 전용 입력창.

숨겨진 필드

  • type="hidden": 화면에는 보이지 않지만, 서버로 어떤 값(회원 등급, 식별 코드 등)을 조용히 넘겨야 할 때 사용합니다.

04-2. HTML5 특수 텍스트 search, url, email, tel

<!-- 검색 상자 (x버튼 제공) -->
<input type="search" id="keyword">
<!-- URL 주소 형식 검증 -->
<input type="url" id="homepage">
<!-- 이메일 형식 검증 (@ 포함 여부) -->
<input type="email" id="mail">
<!-- 전화번호 (모바일 키패드 변경) -->
<input type="tel" id="phone">

HTML5에서 추가된 입력 타입

  • 과거에는 자바스크립트로 복잡하게 검증해야 했던 형식을 HTML5 태그 하나로 처리할 수 있습니다.
  • search: 검색어 입력 필드. 입력란 오른쪽에 내용을 지울 수 있는 x 버튼이 생깁니다.
  • url: 반드시 http://나 https://로 시작하는 유효한 웹 주소 형식이어야 합니다.
  • email: 반드시 @ 기호가 포함된 이메일 주소 형식이어야 제출이 허용됩니다.
  • tel: 모바일 환경에서 이 필드를 터치하면, 숫자 키패드가 자동으로 나타나 사용자 편의를 돕습니다.

04-2. 다중/단일 선택 checkbox, radio

<!-- 복수 선택 (Checkbox) -->
<label>
<input type="checkbox" value="news" checked>
뉴스 메일 수신
</label>
<!-- 단일 선택 (Radio) - name이 같아야 함 -->
<label>
<input type="radio" name="gender" value="M">
남성
</label>
<label>
<input type="radio" name="gender" value="F" checked>
여성
</label>

체크박스 (Checkbox)

  • 여러 개의 항목 중 2개 이상 복수 선택이 가능합니다.
  • 기본적으로 선택되어 있게 하려면 checked 속성을 추가합니다.

라디오 버튼 (Radio)

  • 여러 항목 중 오직 하나만 선택할 수 있습니다. (예: 성별, 혈액형)
  • 단일 선택이 정상 작동하려면 그룹으로 묶일 라디오 버튼들의 name 속성값이 모두 완벽하게 동일해야 합니다.

04-2. 숫자, 날짜, 색상 number, date, color 등

<!-- 스핀 박스 (화살표로 숫자 증감) -->
<input type="number" min="1" max="5" step="1">
<!-- 슬라이더 바 -->
<input type="range" min="1" max="10" value="5">
<!-- 달력 (Date Picker) -->
<input type="date"> <!-- 연/월/일 -->
<input type="month"> <!-- 연/월 -->
<!-- 색상 선택기 (Color Picker) -->
<input type="color" value="#00ff00">

숫자 제어 (number, range)

  • number: 입력창 우측에 숫자를 올리고 내리는 스핀 박스(화살표) 생성.
  • range: 막대를 좌우로 움직이는 슬라이더 바 생성.
  • 공통 속성: min(최솟값), max(최댓값), step(증감 단위).

날짜/시간 제어

  • date: 연, 월, 일 캘린더 UI 제공.
  • 이 외에 month, week, time, datetime-local 타입으로 상세한 시간 선택 가능.
  • color: 브라우저 기본 색상 선택창을 띄워 헥스(Hex) 코드 반환.

04-2. 버튼 및 파일 전송 submit, reset, file

<!-- 폼 데이터 서버 전송 버튼 -->
<input type="submit" value="회원가입">
<!-- 폼 데이터 초기화 버튼 -->
<input type="reset" value="다시 입력">
<!-- 이미지 형태의 제출 버튼 -->
<input type="image" src="btn.png" alt="제출">
<!-- 일반 기능 버튼 (보통 JS와 연결) -->
<input type="button" value="중복 확인">
<!-- 파일 첨부 (찾아보기 버튼) -->
<input type="file">

전송과 초기화

  • submit: 사용자가 입력한 모든 폼 데이터를 action에 지정된 서버로 전송합니다.
  • reset: 폼에 입력했던 모든 내용을 지우고 처음 상태로 되돌립니다.
  • value 속성으로 버튼 겉면에 표시될 텍스트를 바꿀 수 있습니다.

기타 유용한 버튼

  • image: 투박한 기본 submit 버튼 대신 예쁜 이미지를 버튼으로 사용.
  • button: 자체 기능은 없으며, 자바스크립트 함수를 실행할 때 누르는 일반 버튼.
  • file: 로컬 PC의 사진이나 문서를 선택하는 '파일 찾기' 버튼 생성.

04-3. <input> 태그 주요 속성 UX & Validation

<!-- autofocus: 로딩 시 커서 자동 위치 -->
<input type="text" autofocus>
<!-- placeholder: 입력 힌트 표시 -->
<input type="tel"
placeholder="하이픈(-) 없이 입력">
<!-- readonly: 읽기 전용 (수정 불가) -->
<input type="text"
value="admin" readonly>
<!-- required: 필수 입력 지정 -->
<input type="email" required>

UX(사용자 경험) 향상 속성

  • autofocus: 페이지가 열리자마자 해당 폼에 마우스 커서가 깜빡이도록 포커스를 줍니다.
  • placeholder: 사용자가 무엇을 입력해야 할지 알려주는 힌트(연한 텍스트). 입력 시 사라집니다.

데이터 검증 및 제어

  • readonly: 화면에 표시되지만 사용자가 수정할 수는 없게(읽기 전용) 만듭니다. (서버로는 값 전송됨)
  • required: 이 필드를 비워두고 submit 버튼을 누르면 "이 필드를 작성하세요"라는 경고가 뜹니다.

04-4. 여러 데이터 나열하기 <select>, <datalist>

<!-- 1. 드롭다운 목록 (Select) -->
<select id="class">
<optgroup label="공과대학">
<option value="archi">건축공학과</option>
<option value="comp" selected>컴퓨터공학과</option>
</optgroup>
</select>
<!-- 2. 데이터 목록 (자동완성) -->
<input type="text" list="browsers">
<datalist id="browsers">
<option value="Chrome">
<option value="Safari">
</datalist>

드롭다운 (<select>)

  • 클릭하면 옵션들이 아래로 펼쳐지는 드롭다운 목록을 만듭니다.
  • <option>: 실제 선택할 수 있는 항목들입니다. selected 속성으로 기본값을 지정합니다.
  • <optgroup>: 항목이 많을 때 label 속성을 이용해 그룹으로 분류합니다.

데이터 목록 (<datalist>)

  • 텍스트를 직접 입력할 수도 있고, 기존에 제시된 값 중에서 선택할 수도 있는 자동완성 기능을 제공합니다.
  • <input>의 list 속성값과 <datalist>의 id 값을 일치시켜 연결합니다.

04-5. 기타 다양한 폼 요소들 <textarea>, <meter> 등

<!-- 1. 여러 줄 텍스트 입력 (게시판 본문 등) -->
<textarea
name="memo"
cols="50"
rows="5">
메모를 남겨주세요.
</textarea>
<!-- 2. 데이터 사용량 표시 (Meter) -->
<meter
min="0" max="100"
value="64"></meter>
<!-- 3. 작업 진행 상태 표시 (Progress) -->
<progress
value="50" max="100"></progress>

여러 줄 입력 (<textarea>)

  • <input type="text">가 한 줄만 입력된다면, <textarea>는 여러 줄의 긴 텍스트를 입력할 수 있습니다.
  • cols: 글자 수 기준의 가로 너비.
  • rows: 줄 수 기준의 세로 길이 (넘어가면 스크롤 생성).

시각적 상태 표시 바

  • <meter>: 하드디스크 용량, 투표율 등 전체 크기 중 차지하는 비율을 게이지바로 나타냅니다.
  • <progress>: 파일 다운로드 등 작업의 진행 상태(진척도)를 시각적인 바(Bar)로 표시합니다.
