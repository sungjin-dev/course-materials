05-1. 스타일과 스타일 시트 기본 형식

<style>
/* 스타일 규칙 정의 */
p {
text-align: center;
color: blue;
}
</style>
<!-- HTML 적용 예시 -->
<p>
가운데 정렬된 파란색 글씨입니다.
</p>

스타일 (Style)

  • HTML 문서에서 디자인(겉모습)을 결정짓는 규칙입니다. HTML 파일 안에서는 반드시 <style> 태그 안에 작성해야 작동합니다.
  • 선택자 (Selector): 위 코드의 p처럼 스타일 규칙이 적용될 대상을 말합니다.
  • 속성과 값: 속성: 값; 형태로 지정하며 세미콜론(;)으로 구분합니다.

05-1. 스타일을 적용하는 3가지 방법 <style>, <link>

<!-- 1. 인라인 스타일 (태그 내부) -->
<p style="color: blue;">
직접 지정한 파란색 글씨
</p>
<!-- 2. 내부 스타일 시트 (head 영역) -->
<style>
h1 { color: red; }
</style>
<h1>문서 내 일괄 적용 제목</h1>
<!-- 3. 외부 스타일 시트 (.css 파일) -->
<link rel="stylesheet" href="style.css">

적용 방법 요약

  • 인라인: 특정 태그 하나만 바꿀 때 사용.
  • 내부 스타일: 한 페이지의 디자인을 관리할 때 사용.
  • 외부 스타일: 여러 페이지에 공통 디자인을 적용할 때 사용 (가장 권장).

05-2. 주요 선택자 (1) 전체(*), 태그 선택자

<style>
* { margin: 0; } /* 전체 */
p { font-size: 14px; } /* 태그 */
</style>
<!-- HTML 적용 예시 -->
<div>
<p>여백이 없고 14px인 단락입니다.</p>
</div>

기초 선택자

  • 전체 선택자(*): 모든 요소의 기본 여백을 지울 때 유용.
  • 태그 선택자: 특정 종류의 태그를 일괄 디자인할 때 사용.

05-2. 주요 선택자 (2) 클래스(.class), 아이디(#id)

<style>
.bg-red { background: red; }
#header { height: 100px; }
</style>
<!-- HTML 적용 예시 -->
<div id="header">
<p class="bg-red">빨간 배경 단락</p>
<p class="bg-red">재사용된 빨간 배경</p>
</div>

특징 요약

  • 클래스(.): 여러 번 재사용 가능.
  • 아이디(#): 한 페이지에 단 한 번만 사용.

05-2. 주요 선택자 (3) 그룹 선택자 (,)

<style>
h1, h2, .title {
text-align: center;
color: blue;
}
</style>
<!-- HTML 적용 예시 -->
<h1>파란색 중앙 제목 1</h1>
<h2>파란색 중앙 제목 2</h2>
<p class="title">파란색 중앙 클래스</p>

그룹화의 장점

  • 동일한 스타일을 가진 요소를 묶어 코드를 간결하게 유지합니다.

05-3. 캐스캐이딩 스타일 상속과 우선순위 (Cascading)

<style>
.alert { color: red !important; }
#main { color: blue; }
.text { color: black; }
</style>
<!-- 우선순위 예시 -->
<p class="alert" style="color: blue;">빨간색 (강제)</p>
<p id="main" class="text">파란색 (ID 우세)</p>
<!-- 상속 예시 -->
<div style="color: green;">
<p>부모를 따라 초록색이 됩니다.</p>
</div>

점수 산정 방식

  • !important > 인라인 > ID(#) > 클래스(.) > 태그

05-4. CSS3와 브라우저 접두사 Vendor Prefix

<style>
.box:hover {
-webkit-transform: rotate(15deg);
-moz-transform: rotate(15deg);
transform: rotate(15deg);
}
</style>
<!-- HTML 적용 예시 -->
<div class="box">
마우스를 올려보세요!
</div>

호환성 확보

  • 구형 브라우저나 최신 속성의 실험적 지원을 위해 사용합니다.
