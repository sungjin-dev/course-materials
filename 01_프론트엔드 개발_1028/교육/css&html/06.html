06. 텍스트 관련 스타일

웹 문서의 가독성과 디자인을 결정하는 핵심 기법

06-1 글꼴 관련 스타일 (font-family, size)
06-2 텍스트 스타일 (color, shadow)
06-3 문단 스타일 (align, line-height)
06-4 목록과 링크 스타일 (list-style)

06-1. 글꼴 지정 font-family

<style>
body {
font-family:
"맑은 고딕",
돋움,
굴림;
}
</style>
<!-- HTML 적용 예시 -->
<body>
<p>지정한 순서대로 글꼴이 적용됩니다.</p>
</body>

글꼴 우선순위

  • 첫 번째 글꼴이 없으면 두 번째, 그마저 없으면 세 번째 글꼴을 사용합니다.
  • 글꼴 이름에 공백이 있다면 반드시 큰따옴표("")로 묶어줍니다.

06-1. 글꼴 크기 font-size & 단위

<style>
.title { font-size: 2rem; }
.desc { font-size: 16px; }
.small { font-size: 0.8em; }
</style>
<!-- HTML 적용 예시 -->
<h1 class="title">메인 제목</h1>
<p class="desc">일반 설명 텍스트</p>

크기 단위 비교

  • px: 절대적인 고정 크기.
  • em: 부모 요소 기준 상대 크기.
  • rem: 최상위(html) 기준 상대 크기.

06-1. 굵기 및 스타일 weight & style

<style>
.bold-text {
font-weight: 700;
}
.italic-text {
font-style: italic;
}
</style>
<!-- HTML 적용 예시 -->
<p class="bold-text">굵은 글씨</p>
<p class="italic-text">기울임꼴 글씨</p>

속성 상세

  • weight: 숫자(100~900) 또는 키워드(bold, normal) 사용.
  • style: normal, italic, oblique 중 선택.

06-2. 텍스트 꾸미기 color & decoration

<style>
a {
color: rgb(56, 189, 248);
text-decoration: none;
}
.del {
text-decoration: line-through;
}
</style>
<!-- HTML 적용 예시 -->
<a href="#">밑줄 없는 링크</a>
<span class="del">취소선 텍스트</span>

시각적 강조

  • color: 텍스트 자체의 색상을 지정합니다.
  • decoration: none으로 링크 밑줄을 없애거나 underline으로 강조를 추가합니다.

06-2. 텍스트 그림자 text-shadow

<style>
h1 {
text-shadow:
2px 2px 4px #000;
}
</style>
<!-- HTML 적용 예시 -->
<h1>입체감 있는 제목</h1>

그림자 값 순서

  • 가로거리, 세로거리, 번짐정도, 색상 순서로 입력합니다.
  • 여러 개의 그림자를 쉼표(,)로 구분해 겹칠 수 있습니다.

06-3. 문단 스타일 align & line-height

<style>
p {
text-align: justify;
line-height: 1.8;
text-indent: 1em;
}
</style>
<!-- HTML 적용 예시 -->
<p>양쪽 정렬과 줄 간격이 적용된 긴 문장입니다.</p>

가독성 조절

  • justify: 양쪽 끝을 맞춰 깔끔하게 정렬합니다.
  • line-height: 줄 간격을 넓혀 눈의 피로를 줄입니다.
  • text-indent: 문단의 첫 줄을 들여씁니다.

06-3. 말줄임표 처리 overflow & ellipsis

<style>
.cut {
width: 150px;
white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;
}
</style>
<!-- HTML 적용 예시 -->
<div class="cut">
내용이 너무 길면 잘리고 점으로 표시됩니다...
</div>

필수 3가지 속성

  • 줄바꿈 금지(nowrap)
  • 영역 밖 숨김(hidden)
  • 말줄임표 출력(ellipsis)

06-4. 목록 꾸미기 list-style-type

<style>
ul {
list-style-type: square;
}
nav ul {
list-style: none;
}
</style>
<!-- HTML 적용 예시 -->
<ul>
<li>네모 모양 불릿 목록</li>
</ul>

불릿 제거 (none)

  • 네비게이션 메뉴를 만들 때 불릿 기호를 없애기 위해 none을 자주 사용합니다.

06-4. 목록 커스텀 image & position

<style>
.custom {
list-style-image: url('bullet.png');
}
.in {
list-style-position: inside;
}
</style>
<!-- HTML 적용 예시 -->
<ul class="in">
<li>불릿이 텍스트 영역 안으로 들어옵니다.</li>
</ul>

상세 제어

  • 이미지를 직접 불릿으로 쓰거나, 불릿의 위치를 텍스트 안(inside) 또는 밖(outside)으로 조절할 수 있습니다.
