01-1. HTML과의 첫 만남 Tag & Web Standard

<!-- 기본 HTML 문서 예시 -->
<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<title>
기본 HTML 문서
</title>
</head>
<body>
<h1>
시간이란..
</h1>
<p>
내일 죽을 것처럼 오늘을 살고..
</p>
</body>
</html>

HTML이란?

  • 웹에서 자유롭게 오갈 수 있는 웹 문서를 만드는 언어.
  • 모든 문서는 *.html (또는 *.htm) 확장자로 저장.
  • 꺽쇠 괄호(< >)로 묶인 태그(tag)를 사용하여 이미지, 텍스트, 링크 등을 화면에 표시합니다.

웹 표준

  • 웹 사이트를 만들 때 지켜야 하는 약속들을 정리한 것입니다.
  • 표준을 지키면 어떤 브라우저에서도 동일하게 보입니다.

01-3. HTML 문서 기본 구조 (1) <!DOCTYPE>, <html>

<!-- 1. 문서 유형 지정 (HTML5 기준) -->
<!DOCTYPE html>
<!-- 2. HTML 문서의 시작 (언어 설정) -->
<html lang="ko">
<!-- 여기에 head와 body가 들어갑니다 -->
<!-- 3. HTML 문서의 끝 -->
</html>

<!DOCTYPE html>

  • 웹 브라우저에게 현재 문서가 어떤 버전의 HTML로 작성되었는지 알려주는 역할을 합니다.
  • 위의 코드는 최신 표준인 HTML5 문서임을 명시합니다. (<!doctype html>과 동일)

<html>

  • 실제 문서 정보와 내용이 시작되고 끝나는 것을 표시하는 문서의 뿌리(Root) 태그입니다.
  • lang 속성: lang="ko"를 사용하여 해당 문서에서 사용할 기본 언어를 지정할 수 있습니다.

01-3. HTML 문서 기본 구조 (2) <head>, <title>, <meta>

<head>
<!-- 브라우저 탭에 표시될 제목 -->
<title>
문서 제목 표시줄 내용
</title>
<!-- 문자 인코딩 설정 -->
<meta charset="UTF-8">
<!-- 모바일 화면 배율 설정 -->
<meta name="viewport"
content="width=device-width, initial-scale=1.0">
<!-- 검색 엔진을 위한 정보 -->
<meta name="keywords" content="html5, 웹표준">
<meta name="author" content="Kyunghee Ko">
</head>

<head> 영역의 특징

  • 웹 브라우저 화면에는 보이지 않지만, 브라우저가 알아야 할 정보나 문서에 사용할 외부 파일(CSS, JS 등)을 링크하는 곳입니다.

주요 내부 태그

  • <title>: 브라우저의 제목 표시줄(탭)에 표시됩니다.
  • <meta>: 인코딩(한글 깨짐 방지), 스마트폰을 위한 뷰포트(viewport), 키워드, 문서 요약, 작성자 정보 등을 지정합니다.

01-3. HTML 문서 기본 구조 (3) <body>

<body>
<!-- 브라우저 화면에 렌더링될 실제 내용 -->
<h1>
실제 화면에 표시되는 제목
</h1>
<p>
텍스트, 이미지, 목록, 표 등
사용자가 화면을 통해 보게 되는
대부분의 태그가 이곳에 위치합니다.
</p>
</body>

문서의 몸통 <body>

  • 실제로 사용자가 웹 브라우저 화면에서 보게 될 내용을 입력하는 핵심 공간입니다.
  • 이전 문서(02. 텍스트 관련 태그 등)에서 배웠던 대부분의 표시용 태그들이 모두 이 <body>와 </body> 태그 사이에 들어갑니다.

포함할 수 있는 요소

  • 텍스트: 제목(hn), 단락(p) 등
  • 미디어: 이미지(img), 비디오(video)
  • 구조화: 목록(ul, ol), 표(table), 폼(form)
