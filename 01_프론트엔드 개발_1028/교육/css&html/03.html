03-1. 웹 문서와 이미지 GIF, JPG, PNG

<!-- 1. GIF (아이콘, 불릿, 애니메이션) -->
<img src="icon.gif" alt="아이콘">
<!-- 2. JPG/JPEG (사진, 복잡한 색상) -->
<img src="photo.jpg" alt="사진">
<!-- 3. PNG (투명 배경, 고화질) -->
<img src="logo.png" alt="로고">

지원하는 이미지 파일 형식

  • 웹에서는 파일 크기를 작게 유지하면서도 화질을 보장하는 특수한 형식들을 사용합니다.
  • GIF: 최대 256색상 표시. 파일 크기가 매우 작아 아이콘에 적합. 투명 배경과 움직이는 이미지(움짤) 지원.
  • JPG/JPEG: 사진을 위해 개발된 형식. 다양한 색상과 명암을 완벽하게 표현. 저장 반복 시 화질 저하 가능.
  • PNG: 투명 배경을 완벽 지원하면서도 색상 손실이 적어 고화질 유지. 최근 웹에서 가장 많이 사용.

03-1. 이미지 삽입 <img>

<!-- 기본 이미지 삽입 -->
<img
src="images/watch.jpg"
alt="바빠 시리즈 시계">
<!-- 크기 조절 (width, height) -->
<img
src="images/watch.jpg"
width="300"
height="250"
alt="바빠 시리즈 시계">

<img> 태그의 핵심 속성

  • 웹 문서에 이미지를 삽입할 때 사용하며, 닫는 태그가 없습니다.
  • src 속성: 이미지 파일의 경로를 지정. (가장 중요)
  • alt 속성: 이미지가 표시되지 않을 때 나오는 대체 텍스트. 화면 낭독기(스크린 리더)가 이 속성을 읽어주므로 웹 접근성 필수 요소입니다.
  • width / height: 화면에 표시될 이미지의 가로/세로 크기를 지정합니다.

03-1. 이미지에 설명 달기 <figure>, <figcaption>

<!-- 이미지와 설명글을 하나의 세트로 묶기 -->
<figure>
<img
src="watch.jpg"
alt="시계">
<figcaption>
멋진 손목시계 이미지입니다.
</figcaption>
</figure>

논리적 그룹화

  • 이미지와 그 이미지를 설명하는 텍스트를 논리적으로 하나의 세트로 묶어줍니다.
  • <figure>: 설명글을 붙일 대상(이미지, 표, 오디오 등)을 겉에서 감싸는 컨테이너 역할을 합니다.
  • <figcaption>: <figure> 태그 안에 위치하며, 묶인 대상에 대한 설명글(캡션)을 표시합니다.

03-2. 링크 만들기 <a>, href, target

<!-- 1. 기본 텍스트 링크 -->
<a href="http://easyspub.com">
이지스퍼블리싱 홈페이지
</a>
<!-- 2. 새 창에서 링크 열기 -->
<a
href="http://easyspub.com"
target="_blank">
새 창으로 열기
</a>
<!-- 3. 이미지에 링크 걸기 -->
<a href="index.html">
<img src="logo.png" alt="로고">
</a>

하이퍼링크 (Hyperlink)

  • 다른 문서나 사이트로 이동할 수 있게 해주는 기능입니다.
  • <a> 태그 (Anchor): 링크를 만들 때 사용합니다.
  • href 속성: 링크를 클릭했을 때 이동할 목적지의 주소(URL)를 지정합니다.

target 속성

  • 링크된 문서를 어디서 열 것인지 결정합니다.
  • target="_blank": 현재 창을 유지한 채 새 창(새 탭)에서 링크를 엽니다.

03-2. 한 페이지 안에서 점프 앵커 개념

<!-- 1. 이동할 목적지 (도착점) -->
<h2 id="content2">
내용 2 섹션
</h2>
<!-- (매우 긴 문서 내용 생략) -->
<!-- 2. 목적지로 이동하는 링크 (출발점) -->
<a href="#content2">
[내용 2로 바로 이동하기]
</a>
<!-- 맨 위로 돌아가기 예시 -->
<a href="#menu">
[메뉴로 돌아가기]
</a>

앵커 기능이란?

  • 웹 문서가 너무 길 경우, 다른 페이지가 아닌 현재 페이지 내의 특정 위치로 한 번에 이동(점프)하는 기능입니다.
  • 스무스 스크롤링 메뉴, '맨 위로 가기' 버튼, 목차(Index) 이동 등에 흔히 사용됩니다.

앵커 연결 방법

  • 도착점: 이동하고자 하는 목적지 태그에 id="이름" 속성을 부여합니다.
  • 출발점: <a> 태그의 href 속성값으로 #이름 (샵 + id이름)을 적어줍니다.

03-2. 한 페이지 안에서 점프 전체 예제 코드

<!-- 1. 목차 (출발점) -->
<nav id="menu">
<a href="#content1">[1. 회사 소개]</a>
<a href="#content2">[2. 주요 서비스]</a>
</nav>
<!-- 2. 본문 내용 (목적지) -->
<div id="content1">
<h2>1. 회사 소개</h2>
<p>저희 회사는 최고의 기술력을...</p>
<br><br><br> <!-- 스크롤 여백 -->
<!-- 돌아가기 링크 -->
<a href="#menu">[⬆ 메뉴로 돌아가기]</a>
</div>

🔗 책갈피 (Anchor) 동작 흐름

위 코드를 실행하면 상단의 메뉴 클릭 시 해당 id를 가진 하단 내용 영역으로 화면이 즉시 스크롤 됩니다.

✨ 핵심 정리

  • id: 문서 내에서 유일해야 하는 고유 식별자
  • href="#id": 해당 식별자를 찾아가라는 명령어
  • 출발지와 목적지가 한 세트로 구성되어야 완벽하게 동작합니다.
